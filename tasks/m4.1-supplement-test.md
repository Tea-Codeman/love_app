## 轮次 3 · 验证 `recommend_view`（需进入推荐/匹配页）

**为什么之前没触发（已定位为代码 bug，非没进页面）**：`match.vue` 在 `loadRecommend()` 里调用 `track('recommend_view', …)`，但 `<script>` 漏了 `import { track } from '../../utils/track'`。uni-app 编译后运行时报 `ReferenceError: track is not defined`，事件从未发出——**即使你进了页面也不会报**。（`app_open` 能报是因为 `App.vue` 正确引入了 `track`，不代表 `match.vue` 也有。）

**修复**：已在 `match.vue` 补 `import { track, flushTrack }`，并在 `onHide` 调 `flushTrack()` 保证快速切走也能发出。修复 commit 见 `git log`。

**步骤（关键：先重建前端）**：
1. **先在微信开发者工具重新 `npm run dev:mp-weixin` 构建并上传**（否则 DevTools 仍加载旧的 `dist/dev` 包，bug 还在）。
2. 登录后，在首页点「**去匹配破冰 ›**」进入匹配页（顶部标题为「匹配破冰」，内含「为你推荐」候选列表，这就是 `recommend_view` 的触发页，**没有独立的「推荐」页**）。
3. 预期：`events` 新增 1 条 `recommend_view`（props 含 `count` = 候选数）。

**踩坑提示**：该页只在**登录后首页**显示入口；未登录会先走登录/隐私页，看不到按钮。
