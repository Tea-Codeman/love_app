# M8.1 用户侧资质指引清单（账号主体 + 社交类目 + 内容安全权限）

> Agent 出指引，用户侧在「微信公众平台 / 微信小程序后台」操作；达标后告知 Agent，由 Agent 核验 `msgSecCheck` 非 `48001`。
> 本任务为 **M8.3 的前置门禁**：个人主体 / 未认证主体调 `cloud.openapi.security.msgSecCheck` 会报 `48001 api unauthorized`，故必须先行。

## 一、为什么必须做（影响面）

- `cloudfunctions/safety/index.js:23` 的 `USE_WX_SECURITY` 当前为 `false`（原型期本地关键词兜底）。
- 切 `true` 后文本审核走微信官方 `msgSecCheck`。**该接口要求小程序为企业或个体工商户主体且已完成微信认证**，且开通「内容安全」类接口权限。
- 社交 / 陌生人社交 / 婚恋交友属受限制类目，须提交对应资质，否则无法上架或会被下架。

## 二、操作步骤（微信小程序后台 mp.weixin.qq.com）

### 步骤 1：主体升级 + 微信认证
1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 右上角账号主体。
2. 若当前为「个人」主体：进入「设置 → 基本设置 → 账号主体信息 → 修改主体」，按指引升级为**企业**或**个体工商户**（需营业执照、对公账户打款验证等）。
3. 完成**微信认证**（年审费 300 元）：「设置 → 微信认证 → 开通」。认证通过后主体状态显示「已认证」。

### 步骤 2：补充社交类目资质
1. 「设置 → 服务类目 → 添加类目」。
2. 选择 **社交 → 陌生人社交** 或 **社交 → 婚恋交友**（以实际业务为准；本产品为恋爱成长型社交，建议「婚恋交友」）。
3. 按类目要求提交资质（通常含：《增值电信业务经营许可证》ICP 证，或平台认可替代材料；个体户可能接受特定承诺函）。
4. 等待审核（数个工作日），状态变「已通过」。

### 步骤 3：开通内容安全接口权限
1. 「开发 → 接口设置 / 开发管理 → 接口权限」中确认 `security.msgSecCheck`（文本检测）权限为「已获得」。
2. 若未显示：在「服务市场 / 微信云开发 → 内容安全」或对应开通入口申请；企业认证主体通常默认可用。
3. 同时确认 `security.mediaCheckAsync`（图片/异步审核）权限（为 M8 图像审核预留，本期不接回调但权限建议一并开通）。

## 三、达标判定（用户确认后回填此处）

- [ ] 小程序主体类型：______（企业 / 个体工商户）
- [ ] 微信认证状态：______（已认证）
- [ ] 社交类目：______（陌生人社交 / 婚恋交友），审核状态：______（已通过）
- [ ] `msgSecCheck` 接口权限：______（已获得）

## 四、Agent 侧核验（用户达标后执行）

1. 在 CloudBase 控制台或经 CloudBase MCP 调用一次 `safety.checkText`（或 `cloud.openapi.security.msgSecCheck` 空跑），确认无 `48001`。
2. 构造一条违规文本（如含 BLOCKLIST 样例词）+ 一条正常文本，经 `community`/`chat` 触发 `checkText` → 断言违规被拒、正常放行。
3. 核验通过后，Agent 执行 M8.3（flip `USE_WX_SECURITY=true` + 部署 safety + Status=Active）。

## 五、若暂时无法升级主体（降级方案）

- 维持 `USE_WX_SECURITY=false`（本地关键词兜底），v1 以「内部测试 / 受限邀请」方式运行，**不公开上架**。
- 内容安全合规风险由运营方知悉并承担；建议尽快完成企业主体认证后再公开运营。
- 此降级不阻塞 M8.2（隐私文案）/ M8.4（索引），仅阻塞 M8.3（官方真审）。
